AI CRICKET BOT
==============

AI Cricket Bot is a Spring Boot-based REST API that provides intelligent cricket-related responses using AI.  
It allows users to ask natural language questions and receive structured, meaningful cricket insights such as player profiles, team details, match summaries, and statistics.

---

OVERVIEW

AI Cricket Bot acts as an intelligent cricket assistant that processes user queries and returns AI-generated responses using backend services. It is designed to be simple, fast, and extensible for future cricket data enhancements.

---

FEATURES

• AI-powered cricket question answering system  
• Player profiles and career statistics  
• Team and squad information  
• Match summaries and key highlights  
• Tournament and ranking insights  
• RESTful API architecture for easy integration

---

TECHNOLOGY STACK

• Java 17+  
• Spring Boot  
• Spring Web (REST APIs)  
• Maven  
• AI / LLM Integration  
• JSON Processing

---

API USAGE

Example Request:
GET /cricket/ask?query=who is Babar Azam

Example Response:
Babar Azam is a Pakistani international cricketer and former captain of the Pakistan national team, known for his elegant batting style and consistency across formats.

---

PROJECT STRUCTURE

• Controller → Handles incoming API requests  
• Service → Contains business logic and AI processing  
• Model → Defines data structures  
• Configuration → Application setup and dependencies

---

GETTING STARTED

1. Clone Repository  
   git clone https://github.com/your-username/ai-cricket-bot.git

2. Build Project  
   mvn clean install

3. Run Application  
   mvn spring-boot:run
